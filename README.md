# Nina Carducci


## Contexte

Nous proposons nos service à la photographe Nina Carducci pour optimiser son site web

## Objectifs

- Optimiser les images du site.
- Optimiser le code et sa structure afin d'améliorer le chargement et l'accessibilité du site.
- Mettre en place le référencement local
- A l'aide de Lighthouse, faire une optimisation globale tant sur les performances, le SEO et l'accessibilité. 

## Langages utilisées

- HTML
- CSS
- Javascript
   

Projet réalisé dans le cadre de la formation Intégrateur Web d'Openclassrooms
